2. Allgemeines zur Datenverarbeitung

Diese Website ist ein privates, nicht-kommerzielles Projekt einer Pen-&-Paper-Rollenspielgruppe. Es werden nur die Daten erhoben, die für den Betrieb der Website technisch notwendig sind. Eine Weitergabe an Dritte findet nicht statt, außer durch die technisch bedingten Dienste (Cloudflare, siehe unten).

3. Erhobene Daten

3.1 Server-Logfiles

Beim Aufruf der Website werden automatisch folgende Daten in Server-Logfiles gespeichert:

  • IP-Adresse des zugreifenden Geräts
  • Datum und Uhrzeit des Zugriffs
  • Aufgerufene URL
  • HTTP-Statuscode
  • Übertragene Datenmenge
  • Browser-Typ und Betriebssystem

Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der Sicherheit des Betriebs).

3.2 Nutzerkonten

Für die Registrierung werden Benutzername und Passwort erhoben. Das Passwort wird ausschließlich als Hashwert (bcrypt) gespeichert – im Klartext ist es nie auf dem Server hinterlegt. Die Daten werden auf einem privaten Raspberry Pi in Deutschland gespeichert.

3.3 Sitzungs-Cookies

Nach dem Login wird ein Session-Cookie gesetzt (sessionId). Dieser Cookie:

  • ist HttpOnly (kein Zugriff per JavaScript)
  • hat eine Gültigkeitsdauer von 24 Stunden
  • enthält keine personenbezogenen Daten, nur eine zufällige Session-ID
  • ist für den Betrieb der Website technisch notwendig

Rechtsgrundlage: Art. 6 Abs. 1 lit. b DSGVO (Vertragserfüllung / berechtigtes Interesse).

3.4 Charakterdaten

Im Charakter-Manifest gespeicherte Daten (Spielcharaktere, Werte etc.) sind freiwillige Angaben der Nutzer und dienen ausschließlich dem Spielbetrieb der Gruppe.

4. Cloudflare

Der Zugriff auf diese Website erfolgt über Cloudflare Tunnel (Cloudflare Inc., 101 Townsend St., San Francisco, CA 94107, USA). Cloudflare verarbeitet dabei technisch alle eingehenden Anfragen als Relay-Dienst. Cloudflare ist nach dem EU-US Data Privacy Framework zertifiziert. Datenschutzerklärung von Cloudflare: cloudflare.com/privacypolicy
